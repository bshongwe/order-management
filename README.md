# SADC Order Management System

A full-stack order management platform for Southern African Development Community (SADC) markets.

## Project status

Work in progress. The initial engineering foundation is being established.

## Planned technology

- .NET 8 / ASP.NET Core Web API
- Entity Framework Core and SQL Server
- React, TypeScript and Vite
- RabbitMQ for asynchronous integration
- Docker Compose for local development

## Engineering principles

- Modular monolith with clear domain and application boundaries
- SOLID, clean code and explicit business invariants
- Automated tests at unit, integration and end-to-end levels
- Small, reviewable pull requests and continuous integration
- Reliable messaging using transactional outbox and idempotent consumers
